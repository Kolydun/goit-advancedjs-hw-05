# goit-advancedjs-hw-05

Тема 9. Вступ до TypeScript. Домашня робота.

## Опис

Налаштування середовища розробки TypeScript:

- встановлено та налаштовано середовище розробки (Тема 9.4);
- налаштовано компілятор через `tsconfig.json` (Тема 9.5);
- увімкнено **source maps** (`"sourceMap": true`) для налагодження коду у браузері (Тема 9.6).

## Структура

- `src/` — вихідні `.ts` файли, з якими проводилася робота;
- `tsconfig.json` — конфігурація компілятора TypeScript;
- `dist/` — результат компіляції (`.js` + `.js.map`), не комітиться.

## Запуск

```bash
npm install
npm run build   # компіляція src -> dist
npm start       # компіляція та запуск
```

Після `npm run build` у папці `dist` зʼявляться `index.js` та `index.js.map`,
що підтверджує коректне налаштування source maps.
